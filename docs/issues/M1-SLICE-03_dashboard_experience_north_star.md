### 👀 Demo — what works after this merges
Logged-in user accesses `/dashboard` and sees:
1. Total monthly and yearly spend cards calculated with currency symbol.
2. Upcoming renewals in the next 30 days sorted by renewal date ascending.
3. Subscriptions table listing all entries.
4. "Add Subscription" button opening a modal dialog allowing creation of a new subscription in < 60 seconds, which immediately updates the dashboard without a full reload.
5. Server console prints one structured JSON event `renewals_viewed` per dashboard render with `userId`, `upcomingCount`, `windowDays`, and zero financial content.
