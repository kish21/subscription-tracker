### 🔌 Contract — Inputs → Outputs
- **Consumes:** the `renewals_viewed` structured log event defined in `src/schemas/events.ts` (`userId`, `timestamp`, `upcomingCount`, `windowDays` — no financial content), emitted by `[M1-SLICE-03]`
- **Exposes:** `scripts/north-star-count.sh [--days N]` → the distinct-user count for the window, on stdout

### 🔗 Depends On
`[M1-SLICE-03]` (emits the event), `[M3-SLICE-01]` (a deployed log stream to read).

### 👀 Demo — what works after this merges
Running the single documented command against the deployed log stream prints the number of distinct users who viewed their renewals in the last 7 days. A developer following `README.md` alone gets the app running locally in under 15 minutes, timed.

### 🛠️ Implementation Tasks
- [ ] Write `scripts/north-star-count.sh`: filter the JSON log stream to `renewals_viewed`, window by `--days` (default 7), count **distinct** `userId`. Log source configurable — no hardcoded path or host.
- [ ] Write `tests/integration/north-star-event.test.ts` asserting the event fires exactly once per renewals render for an authenticated user, and carries **no** subscription name or price (ADR-006).
- [ ] Write `docs/runbook.md`: deploy, roll back, run a migration, read the metric, respond to an error-reporter alert.
- [ ] Update `README.md` with the public URL, the metric command, and a setup path verified by timing a clean clone.
- [ ] Write feature documentation in `docs/features/north-star-metric.md`.
- [ ] Time a from-scratch local setup and record the actual figure — if it exceeds 15 minutes, fix the setup, not the claim.

### 🔒 Security in the Definition of Done
- [x] The event carries `userId` + timestamp + counts only — a test proves no subscription name, price or email is ever logged (ADR-006).
- [x] The script reads logs read-only and holds no credential in source; any log endpoint or token comes from `.env`.
- [x] No PII is written into `docs/` or `README.md` (no real user ids or emails in examples).
- [x] Runbook documents the fail-closed behaviours rather than ways to bypass them.
